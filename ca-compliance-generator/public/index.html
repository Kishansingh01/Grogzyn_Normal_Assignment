CA Compliance Task Generator - REST API Documentation

Full RESTful specification for integrating with external CA practice management software, ERPs, and automated bots.

POST /api/workflows/generate Accepts serviceType, purpose, priority and generates & stores workflow

Sample Request:

{
  "serviceType": "GST Filing",
  "purpose": "Monthly GST return filing",
  "priority": "high"
}

Sample Response (Simple Format):

{
  "serviceType": "GST Filing",
  "stages": [
    {
      "name": "Document Collection",
      "tasks": ["Collect sales invoices", "Collect purchase invoices"]
    },
    {
      "name": "Verification",
      "tasks": ["Verify invoices", "Reconcile data"]
    },
    {
      "name": "Filing",
      "tasks": ["Prepare return", "Review return", "Submit return"]
    }
  ]
}
GET /api/workflows List all workflows with optional query filters (?serviceType, ?status, ?priority, ?search, ?format=simple)
GET /api/workflows/:id Get specific workflow by MongoDB ObjectId (supports ?format=simple)
PUT /api/workflows/:id Update workflow properties (serviceType, purpose, priority, status)
DELETE /api/workflows/:id Delete a workflow and its associated stages/tasks
POST /api/workflows/:id/stages Add a new stage to an existing workflow
POST /api/workflows/:id/stages/:stageId/tasks Add a task to a stage
PATCH /api/workflows/:id/stages/:stageId/tasks/:taskId Update a task title, assignedTo, or status
PATCH /api/workflows/:id/stages/:stageId/tasks/:taskId/toggle Toggle task status between pending and completed
DELETE /api/workflows/:id/stages/:stageId/tasks/:taskId Delete task from stage
